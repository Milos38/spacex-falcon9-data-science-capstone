# SpaceX Falcon 9 Data Science Capstone

Reconstructed working set for the IBM Applied Data Science Capstone.

## Contents
- API data collection
- Web scraping
- Data wrangling
- EDA and SQL
- Folium mapping
- Plotly Dash dashboard
- Machine-learning classification

## Important
Run and review every notebook before submission. The starter notebooks intentionally do not fabricate outputs or grading results. Some later notebooks require CSV outputs produced by earlier steps or official course datasets.
